#Requisitos do Projeto

## 1. Objetivo

O objetivo desse jogo é trabalhar tecnologia na educação infantil, ajudar na identificação das cores de forma divertida

## 2. Público-alvo

Ele é indicado para crianças que estão na primeira infância , na faixa de 4 a 6 anos. Nessa fase eles estão iniciando a alfabetização com conceitos básicos, e também trabalhando com cores numeros etc. Utilizar de tecnologia para facilitar o aprendizado e fundamental. Esse projeto foi pensado para ser utilizado principalmente no ambiente escolar, ondee podemos despertar a curiosidade das crianças e incluir os professores na evolução dos alunos, atraves de um relatorio de pon tuação que pode ser feito futuramente;

## 3. Problema

O jogo ajuda a manter atenção da criança, despertar curiosidade na área tecnologica, tonar as atividades alternativas e divertidas.

## 4. Objetivos do Jogo

Objetivo geral : Desenvolver memoria e reconhecimento de cores;

Objetivos especificos :
Apresentar diferentes cores;
Estimular a memorização;
Estimular a interação da criança;
Tornar a atividade divertida;
Futuramente, permitir acompanhamento do desempenho;

## 5. Escopo do MVP

Tela inicial;
Cards coloridos;
Selecionar card;
Memorizar posição;
Virar cards;
Verificar cards;
Finalizar partida;
Reiniciar partida;

## 6. Requisitos funcionais

RF01 - O sistema deve apresentar uma tela inicial;
RF02 - O sistema deve apresentar pos cards coloridos;
FR03 - O sistema deve permitir que a criança selecione um card;
FR04 - O sistema deve permitir a seleção de dois cards por rodada;
FR05 - O sistema deve verificar se os cards selecionados possuem a mesma cor;
FR06 - O sistema deve manrter os cards visiveis quando houver um acerto;
FR07 - O sistema deve esconder novamente os cards quando houver um erro;
FR08 - O sistema deve infomar quando todos os pares forem encontrados;

## 7. Requisitos não funcionais

RNF 01- USABILIDADE : A interface deve ser simples e adequada para crianças de 4 a 6 anos;
RNF 02- INTERFACE : Os elementos visuais devem ser grandes e faceis de identificar;
RNF 03- DESEMPENHO : O sistema deve responder rapidamente ás ações do usuario;
RNF 04- ACESSIBILIDADE : O jogo não deve depender exclusivamente ds cores para transmitir informações importantes;
RNF 05- FEEDBACK : O sistema deve fornecer feedback visual para indicar acertos e erros;
RNF 06- SEGURANÇA : O sistema não deve solicitar informações pessoais da criança no MVP;
